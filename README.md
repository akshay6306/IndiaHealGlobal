# IndiaHeal Global – Medical Tourism Portal

A modern, fully responsive medical tourism website for India.

## 🌐 Live Site
Deployed on Netlify.

## 📁 Project Structure
```
medical tourism/
├── index.html      # Main website (all sections)
├── styles.css      # Full stylesheet
├── script.js       # Interactive behaviours
└── netlify.toml    # Deployment config
```

## ✅ Features
- Market data: global comparison table, visa bar chart (2019–2025)
- Transparent care packages with real pricing
- Hospital directory (10 hospitals, filterable by specialty)
- Medical Visa guide (5 steps, fee table, official links)
- Recovery & accommodation finder
- Contact form with validation
- WhatsApp floating widget
- Fully mobile responsive
